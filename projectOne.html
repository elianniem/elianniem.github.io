Collaborative Human-Computer Interaction Interface Project

January 2024 – May 2024

Project Description

This project was completed for the Foundations of Human-Computer Interaction course. The goal was to redesign and modernize the UCF enrollment system, improving usability, user experience, and operational efficiency for IT students and faculty.

  • Led a cross-functional team to improve usability and interface design.
  • Managed the project using a hybrid Agile approach with six phased milestones and a Gantt chart.
  • Facilitated communication between team members to align design, technical implementation, and user requirements.
  • Oversaw front-end development using HTML, CSS, and JavaScript tailored to IT student workflows.
  • Presented iterative prototypes to peers and faculty, incorporating feedback to refine the interface.

Skills Learned

  • Human-Computer Interaction (HCI) Principles
  • Project Management (Agile & Gantt Charts)
  • Front-End Development (HTML, CSS, JavaScript)
  • Team Collaboration & Communication
  • Prototyping and Iterative Design
